# 곁에 디자인 시스템 — 귀갓길

이 문서는 `DESIGN.md`의 실행 규칙이다. 충돌하면 **이 문서가 우선**한다.

`DESIGN.md`의 초기 규칙 중 일부(라디우스 8px 상한, 전면 헤어라인 보더, w900 일변도,
세이지 캔버스 + 딥그린)는 폐기됐다. 아래 "폐기된 규칙"을 반드시 확인할 것.

---

## 1. 제품 톤

`곁에`는 가족·친구·돌봄·여행 동행을 위한 **동의 우선** 위치 공유 앱이다.
감시가 아니라 **기다림**의 톤을 만든다.

- 쓰지 않는 말: 추적, 감시, 몰래, 잠입, 관제
- 쓰는 말: 공유, 확인, 동의, 멈춤, 대략, 신뢰 서클

UI에 이모지를 쓰지 않는다. 아이콘은 SVG/아이콘 폰트로 그린다. (이 규칙은 유지됨)

## 2. 색 토큰

기준 모드는 **다크**다. 이 앱의 피크 사용 시간은 밤이고, 지도는 어두운 배경에서
마커와 경로가 더 잘 읽힌다. 라이트도 동등하게 완성해야 한다.

### 색 사용 규칙

- `brand`는 주 액션과 **정상** 상태에만. 배경을 브랜드색으로 덮지 않는다.
- `warm`은 **도착·온기**의 색이다. 경고 전용이 아니다. 광고에는 쓰지 않는다.
- `alert`는 SOS·확인 필요·삭제에만. 배터리 부족은 `warm`이지 `alert`가 아니다.
- 광고 슬롯은 `surfaceAlt` + `muted`. **브랜드색을 쓰지 않는다** — 광고가 안전 액션보다
  조용해야 한다.
- 딥그린 계열(`#0F6A53` 등)을 지도 위 마커에 쓰지 않는다. OSM 녹지 타일에 묻힌다.

## 3. 형태 언어

```
radius:  sheet 28 · card 16 · chip/button/avatar 999 · small surface 10
```

- **보더로 계층을 만들지 않는다.** 면의 밝기 차(`surface` vs `surfaceAlt`)와 그림자로 만든다.
  선은 구분선(`line`)에만 쓴다.
- 카드 안에 카드를 넣지 않는다. (유지됨)
- 탭 타깃 최소 44px. (유지됨)
- 지도 위 요소(마커·SOS 다이얼)는 **구형 음영과 컬러 글로우 허용**. 없으면 타일에 묻힌다.
  그 외 장식용 그라디언트는 계속 금지.

### 마커는 정보를 나른다

상태를 텍스트로 설명하지 말고 링으로 인코딩한다.

- **링이 채워진 정도** = 배터리 잔량
- **링 스타일** = 공유 정확도 (실선 = 정확·균형 / 점선 = 동네만)
- **링 색** = 상태 (`brand` 정상 / `warm` 오래됨 / `alert` 확인 필요)

정확도 반경 원은 유지한다. 곁에의 차별점이다.
이름 라벨은 **선택된 멤버에만** 띄운다. 전원 상시 노출은 지도를 시끄럽게 만든다.

## 4. 타이포

**Pretendard 한 자루**를 번들해 한글과 라틴을 함께 그린다
(`assets/fonts/`, SIL OFL 1.1, Regular 400 · Bold 700).

초안의 `Geist` + `Pretendard` 조합은 폐기했다. 이 앱의 문장은 대부분 한 줄에서
한글과 숫자를 섞는다 — `배터리 46%`, `정확도 85m`, `집까지 8분`. 두 패밀리를
섞으면 그 줄에서 x-height 와 베이스라인이 어긋나 글줄이 울렁인다. Pretendard 는
metric 이 맞춰진 라틴을 함께 담고 있어 한 자루로 해결되고, 용량도 절반이다.

`tnum` 을 지원하므로 ETA·배터리·시각에 `FontFeature.tabularFigures()` 를 쓴다.
ja·hi·ar 은 Pretendard 가 담지 않으므로, 로케일을 여는 시점에 Noto 서브셋을
추가해 `fontFamilyFallback` 에 잇는다.

- **굵기는 700까지만.** w800·w900을 쓰지 않는다. 위계는 크기로 만든다.
- 스케일: 화면 제목 28 / 섹션 18 / 본문 15 / 보조 13 / 메타 11
- letter-spacing은 큰 제목에만 음수(-0.02em). 본문은 0.
- ETA·배터리·시각·카운터는 tabular numerals.
- **대문자 라벨을 남발하지 않는다.** 데이터 라벨에만 제한적으로.
- `fontSize`를 고정값으로 박되, 반드시 §6의 텍스트 배율 규칙을 함께 지킨다.

## 5. 광고 격리 — 하드 가드

수익은 광고에서 나오지만, **신뢰가 걸린 순간에는 광고가 존재하면 안 된다.**
아래는 취향이 아니라 규칙이다.

`SafeAdSlot`은 다음 화면·상태에 **절대** 들어가지 않는다:

- SOS 발동·카운트다운·전송 후 상황 유지 화면
- OS 권한 요청 전후 교육 화면
- 초대 수락·동의 화면
- 프라이버시/안심 설정 저장 흐름
- 지도 표면 및 지도 위 플로팅 컨트롤
- 온보딩
- 긴급·확인 필요 상태가 떠 있는 동안

허용되는 곳: 기록(활동 목록 이후), 요약/인사이트, 설정 하단 지원 패널.

### 다크패턴 검토

광고로 수익을 내는 안전 앱은 다크패턴 리스크가 구조적으로 높다. 아래를 만들면 안 된다.

- 광고 닫기 버튼을 작게 하거나 지연 노출
- 개인화 광고 동의를 기본 켜짐으로 두기
- 안전 기능에 유료·보상형 광고 유도를 끼워넣기
- "위치 정확도를 높이려면 광고 시청" 류의 교환
- 공유 중단·정확도 하향을 어렵게 만들기 (동의 철회는 동의만큼 쉬워야 한다)

광고 카피에는 **정밀 위치·SOS·권한 데이터가 광고 타깃팅에 쓰이지 않는다**는 사실을
명시한다.

## 6. 텍스트 탄력성 — 배포 전 필수

이 항목은 다국어와 접근성의 **같은 결함**이다. 하나로 묶어서 본다.

필수 텍스트는 다음 조건에서 잘리지 않고 리플로우되어야 한다:

- 좁은 폭 (소형 기기)
- **OS 글자 크기 확대** — `MediaQuery.textScaler`를 존중할 것
- 최장 로케일 (독일어 기준. §7 참조)

**눈으로 보지 말고 테스트로 잡는다.** `test/text_resilience_test.dart` 가 360px
기기에서 배율 1.0 / 1.3 / 2.0 으로 네 탭과 멤버 시트를 띄우고, Flutter 가 던지는
오버플로 예외가 하나라도 있으면 실패한다. 실제로 이 테스트가 배율 1.0 에서도
245px 넘치던 지도 출처 표기를 잡아냈다 — 눈으로는 못 봤던 것이다.

고정 크기를 쓸 때의 규칙:

- 텍스트를 담는 컨테이너에 **고정 `height` 를 주지 않는다.** 꼭 필요하면
  `MediaQuery.textScalerOf(context).scale(...)` 로 계산한다.
  (`MemberAvatarRail`, 지도 `Marker` 상자가 이 방식이다.)
- `maxLines: 1` 은 잘려도 되는 값(이름·라벨)에만. 설명 문장에는 쓰지 않는다.
- `Expanded` 균등 분할 안의 버튼 라벨은 확대·번역 시 가장 먼저 깨진다.

나머지 체크리스트:

- [ ] 대비 4.5:1 이상 (본문). `muted` on `surfaceAlt` 조합은 반드시 측정
- [ ] 포커스 상태가 키보드/스위치 접근에서 보이는가
- [ ] `Semantics` 라벨 — 마커, 시트 행, 상태 배지에 의미 라벨.
      시각 요소를 라벨로 요약했으면 `excludeSemantics: true` 로 중복 낭독을 막는다
- [ ] 모션 축소 설정 존중 (`MediaQuery.disableAnimations`)

## 7. 다국어

기본은 `ko` + `en`이고 **마이그레이션은 끝났다.** UI 문자열은 전부
`lib/l10n/app_ko.arb` / `app_en.arb`에 있고 `AppL10n`으로 읽는다.
`tools/check_hardcoded_strings.py`가 CI에서 새 한국어 리터럴을 **한 건이라도**
막는다. 새 문구는 반드시 ARB에 넣는다.

출시 순서: `ko` → `en` → **`ja`** → **`de`** → `es`·`fr` → `hi` → `ar`

- **`ja`가 영어 다음이다.** 한국어와 텍스트 길이가 거의 같아 레이아웃이 안 깨지고,
  시장 가치가 가장 높다. Noto Sans JP 번들 + 금칙 처리(줄 첫머리 금지 문자) 필요.
  경어는 です・ます조로 통일하되 긴급 화면만 단정형.
- **`de`가 그 다음이다.** 가장 길어지는 언어라 유연 레이아웃을 강제 검증한다.
  독일어를 통과하면 `es`·`fr`은 거의 공짜로 따라온다.
- `hi`는 Noto Sans Devanagari 번들 + 행간 재조정.
- `ar`은 RTL 전면 전환: `EdgeInsets.only` → `EdgeInsetsDirectional`,
  `Positioned` → `PositionedDirectional`. **지도 자체는 반전하지 않는다.**

### 표시 문자열을 판별에 쓰지 말 것

이 저장소에서 같은 버그가 네 번 나왔다. 전부 **표시용 값을 신원으로 재사용**한
경우다.

- 모델이 `Color`를 들고 있어 화면이 한 테마에 묶였다 → `GyeoteTone`
- 모델이 렌더된 문구를 들고 있어 한 언어에 묶였다 → 사실만 담고 그릴 때 계산
- 필터가 `event.type == '확인'` 으로 비교했다 → `HistoryEventType` enum
- 배너가 `message.contains('못했습니다')` 로 오류를 판별했다 → 명시적 플래그

규칙: **보여주는 값과 판단하는 값을 같은 것으로 쓰지 않는다.** 모델과 상태는
역할·enum·불리언을 담고, 문구는 그릴 때 로케일에서 만든다.

### 지역마다 값이 달라지는 항목 (문자열이 아니다)

문자열로 다루면 안전 기능이 오작동한다. 반드시 지역 설정값으로 분리한다.
구현은 `lib/src/core/i18n/region_settings.dart`에 있다.

- **긴급번호** — 한국 112·119, 일본 110·119, 독일 110·112, 미국 911,
  인도·스페인·프랑스 112, 사우디 999. 한·일·독이 숫자를 부분 공유해 더 위험하다.
- **거리 단위** — `en-US`만 마일/피트. 반경 프리셋(100m·300m·500m)도 재설계 대상.
- **시간 표기** — 12시간제(`en-US`, `hi`, `ar`) / 24시간제(`ko`, `ja`, `de`, `es`, `fr`).
- **이름 이니셜** — `name.substring(0, 1)`을 쓰지 말 것. 데바나가리·아랍 문자에서
  결합 문자가 잘려 깨진다. `characters` 패키지의 grapheme 단위를 쓴다.

## 8. 폐기된 규칙

`DESIGN.md`에 남아 있으면 **따르지 말 것.**

| 폐기 | 대체 |
|---|---|
| "radius 8px 이하" | sheet 28 / card 16 / chip·avatar 999 |
| 모든 요소에 헤어라인 보더 | 면의 밝기 차 + 그림자. 선은 구분선에만 |
| 앱 이름·제목 heavy(w800·w900) | 최대 700. 위계는 크기로. 번들 폰트도 400/700 두 자루뿐이다 |
| Geist + Pretendard 혼용 | Pretendard 단일. 한 줄에 두 문자가 섞이므로 metric 이 맞아야 한다 |
| Canvas `#F4F6F1` / Surface `#FFFEFA` | §2 따뜻한 중성 |
| Primary `#0F6A53` | `brand` — 지도 위 가독성 때문 |
| Amber는 광고·주의 전용 | `warm`은 도착·온기. 광고는 중성 회색 |
| 라이트 모드 전용 | 다크 기준 + 라이트 동등 완성 |

유지되는 규칙: 이모지 금지, 카드 중첩 금지, 44px 탭 타깃, 4pt 간격 기준,
정확도 4단계(정확·균형·동네만·숨김), 곁핀 사용 범위, 광고 격리.

## 9. 작업 순서

UI를 새로 만들거나 크게 고칠 때:

1. **plan** — 이 문서의 토큰으로 색·형태·타이포를 먼저 확정한다.
   외부 팔레트 카탈로그에서 고르지 않는다.
2. **build** — 토큰만 참조한다. 리터럴 색상값을 위젯에 직접 쓰지 않는다.
3. **check** — §5 광고 격리, §6 텍스트 탄력성 체크리스트를 통과시킨다.
4. **verify** — `flutter analyze` + `flutter test`
   + `python tools/check_hardcoded_strings.py`.
   Flutter SDK가 없는 워크스페이스라면 **검증하지 못했다고 명시**한다.

### 알려진 미해결 (스키마 변경 필요)

- `PlaceAlertQuietHours.label`이 DB에 저장된 뒤 번역 문구와 비교된다. 다른
  언어를 쓰는 멤버가 프리셋을 순환시키면 첫 값으로 되돌아간다. 라벨 대신
  **프리셋 키를 저장**해야 한다.
- 방해 금지 시간대가 `Asia/Seoul`로 고정돼 있다. 다른 지역에서는 조용한 시간이
  어긋난다. 기기의 IANA 존을 받아와야 한다.
- `ja`·`hi`·`ar` 용 문자 폰트는 아직 없다. Pretendard 는 가나·한자·데바나가리·
