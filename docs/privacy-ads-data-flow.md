# 프라이버시, 광고, 데이터 요청 플로우

Date: 2026-05-30

## 프라이버시 대시보드

프라이버시 화면은 네 가지 상태를 한곳에 둔다.

- 공유 범위: 서클별 precise, balanced, area, hidden, sos_only.
- 조회 기록: `viewer_logs` 기반으로 최근 조회자와 목적을 표시.
- 광고 데이터: 개인화 광고 여부, 민감 카테고리 차단, 정밀 위치 광고 차단.
- 내 데이터: 위치 기록 보관, 동행 경로 보관, 내보내기/삭제 요청 상태.

Flutter scaffold 연결:

- `공유 멈춤`은 첫 활성 서클의 공유 정책을 1시간 `hidden`/disabled 상태로 저장한다.
- 광고 스위치는 `ad_preferences`를 읽고 저장하며, 정밀 위치 광고 사용은 항상 `false`로 유지한다.
- `내보내기`와 `기록 삭제`는 `data_requests`에 요청을 남기고 서버 작업자가 처리한다.

## 광고 격리

- 광고 SDK에는 raw coordinate, shared coordinate, circle id, session id, SOS state를 넘기지 않는다.
- SOS, 권한 요청, 초대 수락, 데이터 삭제/내보내기 화면에는 광고를 표시하지 않는다.
- 미성년자 또는 동의 미확인 계정은 비개인화 광고만 사용한다.
- 광고 실패는 지도, SOS, 동행, 장소 알림 실패로 전파되지 않는다.

## 데이터 요청

1. 사용자가 내보내기, 위치 기록 삭제, 계정 삭제를 요청한다.
2. 앱은 `data_requests`에 pending 요청을 만든다.
3. 서버 worker가 위치 기록, 최신 위치, 동행 세션, 장소 알림, 디바이스 토큰, 저장소를 범위별로 처리한다.
4. 완료 후 앱은 결과 URL 또는 완료 상태만 표시한다.
5. 삭제 요청 중인 데이터는 즉시 일반 조회에서 숨긴다.

## 릴리스 차단 조건

- 공유 일시 중지 후에도 위치가 보인다.
- viewer log를 사용자가 임의 수정/삭제할 수 있다.
- 광고 SDK 네트워크 요청에 위치, 서클, 세션 식별자가 섞인다.
- 데이터 삭제 요청 후 기록 화면에서 동일 위치가 재조회된다.
- 계정 삭제가 앱 안에서 시작되지 않는다.
