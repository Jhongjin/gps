시행일: (게시일) · 곁에(Gyeote) · 문의 woolelagtm@gmail.com

초안입니다. 법률 검토를 마치기 전에는 스토어 양식에 연결하지 마세요. 이 문서는 앱 코드가 실제로 수집·저장·전송하는 것만 적었습니다 — 항목을 더하거나 빼려면 코드부터 바꿉니다.

1. 우리가 누구인가

곁에는 가족·친구·돌봄 관계에서 서로 동의한 사람끼리 위치를 공유하는 앱입니다. 운영자이자 개인정보 보호책임자: 전홍진 (개인 개발자) · woolelagtm@gmail.com.

2. 수집하는 정보

계정

  • 이메일 주소, 비밀번호(해시로만 저장), 표시 이름
  • 목적: 로그인, 서클 안에서 이름 표시

위치

  • 공유 좌표: 사용자가 고른 정확도(정확·균형·동네·숨김)로 줄이고, 등록한 민감 장소 안에서는 그 장소의 가운데 지점으로 바꾼 뒤에만 기기를 떠납니다. 정확한 원시 좌표는 기기 안에서만 쓰이고 서버에 저장되지 않습니다.
  • 정확도(미터), 배터리 잔량, 위치 출처(GPS/네트워크), 기록 시각
  • 목적: 서클 멤버에게 현재 위치와 이동 경로 표시, 장소 도착·이탈 알림, 동행 모드, 긴급(SOS) 공유, 약속 장소까지 남은 시간 추정
  • 백그라운드 수집은 동행 모드와 장소 알림을 위해서만, 사용자가 켠 동안에만 합니다.

활동

  • 확인 응답(도착했어요·가는 중·괜찮아요·전화해줘), 장소 알림 이벤트, 동행 세션의 시작·종료, 약속(이름·장소·시각·참석 여부)
  • 열람 기록: 어떤 서클 멤버가 언제 어떤 정확도로 내 위치를 열어 봤는지. 보여지는 사람만 자기 기록을 볼 수 있습니다.

기기

  • 앱이 만든 기기 식별자, 플랫폼, 권한 상태
  • 목적: 위치 업로드 출처 확인, 기기별 설정

기기에만 남고 서버로 가지 않는 것

  • 등록한 민감 장소 목록(이름·좌표·반경) — 서버에 저장 공간이 없습니다
  • 정확한 원시 좌표
  • 광고 식별자 — 현재 앱에 광고 SDK가 없습니다. 도입하더라도 정밀 위치, 서클 관계, SOS 상태는 광고에 쓰지 않습니다.

  • 동행 세션 경로: 세션 종료 뒤 요약만 남고 24시간 안에 지웁니다.

  • 계정 정보: 계정 삭제 시 즉시

  • 계정 삭제 — 계정과 서클 참여, 위치 기록, 확인 기록, 열람 기록이 즉시 지워집니다. 되돌릴 수 없습니다. 자세한 절차: 계정 삭제 안내

  • 공유 정확도 변경, 공유 일시정지, 민감 장소 등록

6. 아동

곁에는 보호자가 계정을 만들고 관리하는 것을 전제로 합니다. 만 14세 미만(대한민국) 또는 13세 미만(미국 등) 아동의 계정 생성은 허용하지 않으며, 아동의 위치는 보호자 계정의 서클 안에서만 공유됩니다. 아동을 대상으로 한 광고나 광고 식별자 수집은 하지 않습니다.

7. 보안

전송은 HTTPS로 암호화합니다. 위치 업로드 대기열은 기기 안에서 암호화해 보관합니다. 서버에서는 행 단위 접근 제어로 서클 밖 사용자가 위치를 읽을 수 없게 합니다.

8. 변경

방침이 바뀌면 앱 안 안심 화면과 이 페이지에 게시하고, 중요한 변경은 로그인 시 알립니다.
