# 가족/친구 위치공유 앱 UX/제품 디자인 문서

## 1. 제품 방향

### 제품 한 줄 정의

가족, 친구, 커플, 여행 동행자가 서로 동의한 범위 안에서 위치와 안전 상태를 확인하고, 긴급 상황에는 즉시 도움을 요청할 수 있는 무료 위치공유 앱.

### 핵심 전략

- 모든 핵심 기능은 유료 잠금 없이 제공한다.
- 수익은 광고 기반으로 만들되, 위치 확인, SOS, 동의, 프라이버시 설정 같은 신뢰 핵심 순간에는 광고를 절대 끼워 넣지 않는다.
- 기존 위치공유 앱의 강점인 실시간 위치, 장소 알림, 위치 기록, SOS, 배터리 알림, 고령자 케어를 MVP에 반영하되, 차별점은 "감시가 아닌 합의된 안심"으로 둔다.
- 사용자는 항상 "누가 내 위치를 볼 수 있는지", "언제까지 공유 중인지", "어느 정도 정확도로 공유하는지"를 이해하고 바꿀 수 있어야 한다.
- 광고도 사용자가 통제할 수 있게 한다. 광고 개인화, 민감 카테고리, 음소거, 빈도 제한, 보상형 광고 선택권을 명확히 제공한다.

### UX 원칙

- 안심 우선: 공포, 감시, 추적 느낌보다 연결, 확인, 도움의 톤을 사용한다.
- 상호 동의 기본: 몰래 추적을 만들 수 없는 구조로 설계한다.
- 지도는 빠르게: 앱 실행 후 2초 안에 마지막 위치 또는 로딩 상태가 보여야 한다.
- 긴급 행동은 한 손 조작: SOS, 전화, 현재 위치 공유는 엄지 영역에서 가능해야 한다.
- 설정은 숨기지 않기: 프라이버시, 배터리, 광고 설정은 하위 깊이를 줄이고 검색 가능한 구조로 둔다.

## 2. 핵심 사용자 페르소나

### 페르소나 A. 초등학생 자녀를 둔 부모

- 이름: 김민정, 39세, 맞벌이 부모
- 상황: 아이가 학원, 학교, 놀이터를 오가고 전화 응답이 늦을 때 불안하다.
- 목표: 아이가 안전한 장소에 도착했는지 자동으로 알고, 긴급 상황에서 빠르게 연락받고 싶다.
- 주요 행동: 학교/학원/집 장소 알림 설정, 자녀 배터리 확인, 이동 기록 확인, SOS 수신.
- 불안 요소: 아이가 감시받는다고 느끼는 것, 배터리 소모, 위치가 부정확할 때 생기는 오해.
- 성공 기준: "일일이 전화하지 않아도 아이의 안전 상태가 확인된다."
- 디자인 요구:
  - 보호자용 대시보드에서 자녀의 현재 장소, 배터리, 마지막 업데이트 시간을 한눈에 표시한다.
  - 자녀 앱에는 공유 상태와 일시 숨김 요청 기능을 명확히 제공한다.
  - 장소 알림은 "도착", "출발", "예상 시간보다 늦음"까지 단순한 옵션으로 제공한다.

### 페르소나 B. 친구/커플/여행 동행자

- 이름: 이준호, 27세, 친구들과 해외여행 중
- 상황: 여행지에서 일행이 따로 움직이다가 다시 만나야 하거나, 늦은 밤 귀가를 서로 확인한다.
- 목표: 특정 기간 동안만 위치를 가볍게 공유하고, 약속 장소로 쉽게 합류하고 싶다.
- 주요 행동: 임시 서클 만들기, 링크 초대, 만남 장소 지정, 실시간 위치 확인, 일정 종료 후 공유 자동 해제.
- 불안 요소: 여행 후에도 위치 공유가 계속되는 것, 친구에게 너무 정확한 위치가 계속 보이는 것, 데이터/배터리 사용량.
- 성공 기준: "여행 중에는 편하고, 끝나면 자동으로 깔끔하게 꺼진다."
- 디자인 요구:
  - 서클 생성 시 "1시간", "오늘 자정까지", "여행 종료일까지" 같은 만료 시간을 먼저 고르게 한다.
  - 커플/친구 모드에서는 정확도 선택과 일시 숨김을 더 눈에 띄게 제공한다.
  - 지도에서 "중간 지점 보기", "모두에게 집결 위치 공유"를 빠르게 사용할 수 있게 한다.

### 페르소나 C. 고령 가족 케어 보호자

- 이름: 박성호, 51세, 고령 부모를 돌보는 자녀
- 상황: 부모님이 외출 후 길을 잃거나, 장시간 휴대폰을 사용하지 않을 때 걱정된다.
- 목표: 부모님의 이동 상태와 비활성 상태를 무리 없이 확인하고, 위험 상황을 빨리 알아차리고 싶다.
- 주요 행동: 안전 구역 설정, 장시간 미사용 알림, 배터리 부족 알림, 마지막 위치 확인, 가족 공동 보호자 초대.
- 불안 요소: 부모님이 앱 조작을 어려워하는 것, 위치 공유가 사생활 침해처럼 느껴지는 것, 응급 상황에서 단계가 복잡한 것.
- 성공 기준: "부모님은 복잡한 조작 없이 쓰고, 가족은 필요한 순간만 확인한다."
- 디자인 요구:
  - 고령자용 홈은 큰 글자, 큰 SOS, 공유 상태 표시, 보호자 전화 버튼 중심으로 단순화한다.
  - 보호자는 "장시간 이동 없음", "휴대폰 미사용", "안전 구역 이탈" 알림을 켤 수 있다.
  - 위치 기록은 상세 추적보다 "오늘의 이동 요약"과 "마지막 안전 확인"을 먼저 보여준다.

## 3. 모바일 앱 IA

### 하단 내비게이션

1. 지도
   - 현재 서클 멤버 위치
   - 멤버 상세 바텀시트
   - 장소 알림 빠른 추가
   - 집결 위치 공유
   - SOS 플로팅 버튼

2. 서클
   - 내 서클 목록
   - 멤버 관리
   - 초대 링크/연락처 초대
   - 권한과 공유 기간
   - 서클별 광고/알림 설정

3. 알림
   - 장소 도착/출발 알림
   - SOS 기록
   - 배터리/비활성 알림
   - 누가 내 위치를 확인했는지

4. 기록
   - 오늘 이동 요약
   - 날짜별 위치 기록
   - 장소 체류 시간
   - 기록 공유/삭제

5. 내 설정
   - 프라이버시
   - 위치 정확도
   - 배터리 모드
   - 광고 설정
   - 계정/기기/고객지원

### 전역 요소

- SOS 버튼: 모든 주요 화면 우하단 고정. 단, 타이핑/지도 편집 중에는 접힌 상태로 표시한다.
- 공유 상태 배지: 상단 또는 지도 하단에 "정확 위치 공유 중", "대략 위치 공유 중", "일시 숨김 중"을 상시 노출한다.
- 위치 조회 알림: 사용자가 켜면 "방금 민정님이 내 위치를 확인했어요"를 푸시 또는 알림 탭에 표시한다.
- 광고 안전 계층: 광고는 컨텐츠 흐름 중간에만 들어가며, 긴급/권한/위치 확인의 핵심 버튼 주변에는 배치하지 않는다.

## 4. 핵심 플로우

### 4.1 온보딩/동의

목표: 위치공유의 가치를 설명하되, 동의와 통제권을 먼저 각인시킨다.

단계:

1. 시작 화면
   - 카피: "서로 동의한 사람끼리만 위치를 공유해요."
   - CTA: "시작하기"

2. 사용 목적 선택
   - 가족 안전
   - 친구/커플
   - 여행
   - 고령 가족 케어
   - 선택값은 초기 추천 설정에만 사용하고 언제든 변경 가능하다고 안내한다.

3. 위치공유 약속
   - "몰래 추적은 지원하지 않습니다."
   - "내 위치를 보는 사람과 공유 정확도는 언제든 바꿀 수 있습니다."
   - 체크박스: 서비스 이용 동의, 위치기반서비스 동의, 개인정보 동의.

4. 권한 요청 준비 화면
   - 위치 권한: 앱 사용 중/항상 허용 차이 설명.
   - 알림 권한: 장소 도착, SOS, 배터리 알림 수신 목적 설명.
   - 백그라운드 위치: 실시간 공유와 장소 알림에 필요한 이유를 설명.
   - OS 권한 팝업 직전에 단일 목적만 말한다.

5. 내 프로필 설정
   - 이름, 사진 또는 이니셜, 관계 유형.
   - 기본 공유 정확도 선택: 정확 / 표준 / 대략.

6. 서클 생성 또는 참여
   - "새 서클 만들기"
   - "초대 코드 입력"
   - "초대 링크로 참여"

성공 상태:

- 사용자는 현재 어떤 권한을 허용했는지 이해한다.
- 사용자는 첫 서클을 만들거나 초대받은 서클에 들어간다.
- 앱은 빈 지도 대신 "아직 공유 중인 멤버가 없어요"와 초대 CTA를 보여준다.

### 4.2 서클 초대

목표: 가족/친구를 빠르게 초대하되, 초대받은 사람의 동의와 공유 범위를 명확히 한다.

단계:

1. 서클 만들기
   - 서클 이름: "우리 가족", "오사카 여행", "퇴근길 안심"
   - 서클 유형 선택: 가족 / 친구 / 여행 / 케어
   - 공유 기간: 계속 / 오늘까지 / 직접 지정.

2. 초대 방식 선택
   - 링크 공유
   - 연락처 초대
   - QR 코드
   - 초대 코드

3. 초대 미리보기
   - 초대받는 사람이 보게 될 문구를 보여준다.
   - 예: "민정님이 '우리 가족' 서클에서 위치를 서로 공유하자고 초대했어요."

4. 참여자 동의
   - 참여자는 공유 정확도, 공유 기간, 알림 수신 여부를 선택한다.
   - 미성년자 계정은 보호자 동의와 자녀용 설명 화면을 분리한다.

5. 완료
   - 지도 화면으로 이동.
   - 새 멤버가 아직 권한을 허용하지 않았으면 "권한 설정 대기 중"으로 표시한다.

### 4.3 지도

목표: 가장 자주 쓰는 화면에서 위치, 상태, 행동을 빠르게 확인한다.

핵심 구성:

- 상단: 서클 전환, 내 공유 상태 배지, 알림 아이콘.
- 지도: 멤버 아바타 핀, 안전 장소 영역, 내 위치.
- 하단 바텀시트: 멤버 목록, 마지막 업데이트 시간, 배터리, 이동/정지 상태.
- 빠른 액션: 전화, 메시지, 길찾기, 장소 알림 추가, 집결 위치 공유.
- 상태 표현:
  - 정확 위치: 선명한 핀과 주소.
  - 대략 위치: 반경 원과 "약 500m 범위" 표시.
  - 일시 숨김: 회색 아바타와 "공유 일시 중지" 표시.
  - 오래된 위치: 점선 핀과 "12분 전" 강조.
  - 실제 지도 구현은 멤버 핀 아래에 공유 정밀도/정확도 반경 원을 먼저 그려 위치 신뢰도를 보이게 한다.

지도 내 광고 원칙:

- 지도 위에는 배너 광고를 올리지 않는다.
- 멤버 핀, SOS, 길찾기 버튼 주변에는 광고를 배치하지 않는다.
- 지도 화면에서 광고가 필요하면 바텀시트를 완전히 내렸을 때 하단의 작은 네이티브 카드로만 노출한다.

### 4.4 장소 알림

목표: 자주 가는 장소의 도착/출발을 자동으로 알린다.

단계:

1. 지도에서 장소 길게 누르기 또는 장소 탭에서 "장소 추가".
2. 장소 이름 선택: 집, 학교, 회사, 학원, 병원, 직접 입력.
3. 반경 설정: 100m, 300m, 500m, 직접 조정.
4. 대상 선택: 누구의 도착/출발을 받을지 선택.
5. 현재 Flutter 지도에는 100m, 300m, 500m 반경 미리보기가 먼저 구현되어 있으며, 저장은 대상 선택과 동의 정책 뒤에 연다.
5. 알림 조건:
   - 도착하면 알림
   - 떠나면 알림
   - 정해진 시간까지 도착하지 않으면 알림
   - 장시간 머무르면 알림
6. 저장 전 요약:
   - "지우가 학교 반경 300m 안에 도착하면 알려드려요."

주의:

- 저장 버튼 근처에 광고를 두지 않는다.
- 장소 알림은 무제한 제공하되, 너무 많은 알림 설정 시 배터리 영향 안내를 제공한다.
- 장소별로 조용한 시간대를 둘 수 있게 한다.

### 4.5 SOS

목표: 위기 상황에서 생각할 필요 없이 도움을 요청한다.

단계:

1. SOS 버튼 탭.
2. 3초 카운트다운.
   - 취소 가능.
   - 길게 누르면 즉시 발송 옵션 제공.
3. 발송 내용:
   - 현재 위치
   - 실시간 이동 링크
   - 배터리 상태
   - 선택 시 주변 소리 짧은 녹음
   - 선택 시 112/119 안내 또는 전화 연결
4. 수신자 화면:
   - 전체 화면 긴급 알림.
   - "위치 보기", "전화하기", "길찾기", "다른 보호자에게 공유".
5. 종료:
   - 발신자가 "안전해요"를 누르면 서클에 종료 알림.

SOS 광고 금지:

- SOS 버튼, 카운트다운, 발송 완료, 수신 알림, 긴급 위치 지도에는 광고를 절대 표시하지 않는다.
- 보상형 광고, 전면 광고, 앱 오픈 광고가 SOS 흐름을 가로막지 않도록 전역 예외를 둔다.

### 4.6 기록

목표: 안전 확인과 회고에 필요한 만큼만 이동 이력을 보여준다.

구성:

- 오늘 요약: 이동 거리, 주요 장소, 마지막 안전 확인.
- 타임라인: 시간, 장소, 체류 시간, 이동 구간.
- 지도 경로: 선택한 날짜의 경로를 얇은 선으로 표시.
- 필터: 사람, 날짜, 장소.
- 삭제: 하루 기록 삭제, 특정 장소 숨김, 전체 기록 자동 삭제 주기.

프라이버시:

- 기본 보관 기간은 30일로 제안한다.
- 사용자가 7일, 30일, 90일, 1년 중 선택할 수 있다.
- 서클별로 기록 공유 여부를 끌 수 있다.
- 다른 사람의 기록 조회 시 조회 로그를 남긴다.

광고 위치:

- 오늘 요약 아래, 타임라인 시작 전 네이티브 광고 1개.
- 날짜 전환 직후에는 광고를 띄우지 않는다.
- 기록을 삭제하거나 내보내는 화면에는 광고를 표시하지 않는다.

### 4.7 프라이버시/광고 설정

목표: 사용자가 위치공유와 광고 경험을 직접 통제한다는 감각을 준다.

프라이버시 설정:

- 내 위치를 볼 수 있는 사람
- 사람별 공유 정확도
- 사람별 공유 시간
- 일시 숨김
- 위치 조회 알림
- 위치 기록 보관 기간
- 기록 다운로드/삭제
- 차단한 사용자

광고 설정:

- 광고 개인화 켜기/끄기
- 민감 광고 카테고리 제한
- 음소거 기본값
- 앱 오픈 광고 허용 여부
- 보상형 광고로 24시간 광고 줄이기
- "왜 이 광고가 보이나요?" 설명

광고 설정 원칙:

- 광고를 끄는 기능을 유료로 판매하지 않는다.
- 보상형 광고는 기능 해금이 아니라 광고 빈도 감소, 앱 운영 후원, 테마 배지 같은 비핵심 보상에만 사용한다.
- 위치, 건강, 고령자 케어, 미성년자 관련 민감 정보는 광고 타게팅에 사용하지 않는다.

## 5. UI 톤앤매너

- "안전해요"

피해야 할 카피:

- "몰래 확인"
- "상대방 모르게"
- "완벽 통제"

주요 컬러:

- Trust Teal `#1F8A8A`: 공유 중, 연결, 기본 CTA.

- Care Green `#38A169`: 안전 도착, 정상 상태.

- White `#FFFFFF`: 카드와 바텀시트.

사용 원칙:

### 타이포그래피

- 기본: 시스템 폰트.
- 지도 핀 라벨: 12-13sp.
- 바텀시트 제목: 18sp, 세미볼드.
- 본문: 15-16sp.
- 고령자 케어 모드: 기본 18sp 이상, 버튼 높이 52dp 이상.

### 컴포넌트 원칙

- 지도 핀:
  - 원형 아바타 + 상태 링.
  - 배터리 낮음은 작은 배터리 아이콘으로 보조 표시.
  - 위치 오래됨은 점선 링과 시간 배지.

- 바텀시트:
  - 지도와 함께 쓰는 기본 정보 패널.
  - 3단 높이: 접힘 / 중간 / 전체.
  - 중간 높이에서 핵심 액션 4개가 보여야 한다.

- 버튼:
  - 기본 CTA는 채움 버튼.
  - 위험 행동은 코랄 계열.
  - 파괴적 행동은 확인 바텀시트 후 실행.

- 토글/세그먼트:
  - 공유 정확도: 정확 / 표준 / 대략.
  - 배터리 모드: 실시간 / 균형 / 절전.
  - 공유 기간: 계속 / 오늘까지 / 직접 지정.

- 알림 카드:
  - 사람, 장소, 시간, 행동 CTA를 한 줄 구조로 스캔 가능하게 배치한다.
  - SOS는 일반 알림과 시각적으로 확실히 분리한다.

## 6. 광고 UX 원칙

### 허용 위치

- 기록 탭의 오늘 요약 아래 네이티브 광고.
- 알림 탭에서 과거 일반 알림 5개 이후 네이티브 광고.
- 서클 탭 하단의 운영 후원 카드.
- 설정의 광고 설정 화면 안에서 광고 경험 미리보기.
- 앱을 오래 사용한 후 세션 종료 시점의 저빈도 전면 광고.
- 보상형 광고: 사용자가 명시적으로 선택할 때만 재생.

### 금지 위치

- 온보딩 동의 화면.
- OS 권한 요청 직전/직후.
- 지도 첫 진입 후 위치 로딩 중.
- 멤버 위치 확인 버튼 주변.
- SOS 전체 흐름.
- 장소 알림 저장/삭제 화면.
- 프라이버시 설정 저장 화면.
- 위치 기록 삭제/내보내기 화면.
- 미성년자 프로필 화면.
- 고령자 케어 긴급 알림 화면.
- 배터리 부족, 위치 끊김, 안전 구역 이탈 같은 위험 알림 화면.

### 빈도와 품질

- 한 세션의 전면 광고는 최대 1회.
- 지도 탭에서는 배너 고정 노출을 하지 않는다.
- 네이티브 광고는 컨텐츠 카드와 구분되도록 "광고" 라벨을 항상 표시한다.
- 광고 닫기 버튼은 최소 44dp 터치 영역을 제공한다.
- 광고가 로드되지 않아도 화면 레이아웃이 흔들리지 않게 고정 높이 플레이스홀더를 둔다.

## 7. 접근성/신뢰 장치

### 누가 내 위치를 보는지

- 내 설정 첫 화면에 "현재 내 위치를 볼 수 있는 사람" 카드 표시.
- 사람별 마지막 조회 시간 표시.
- 조회 로그 예시: "오늘 18:42 민정님이 내 위치를 확인했어요."
- 서클별 공유 상태를 한 화면에서 끄거나 조정 가능.
- 새 멤버가 들어오면 기존 멤버에게 알림.

### 일시 숨김

- 빠른 설정과 지도 상단 배지에서 접근.
- 옵션:
  - 15분 숨김
  - 1시간 숨김
  - 오늘까지 숨김
  - 직접 지정
- 숨김 중에는 상대에게 "일시 숨김 중"으로 표시하고, 마지막 정확 위치를 계속 보여주지 않는다.
- SOS 발송 시에는 사용자가 동의한 긴급 예외 정책에 따라 일시 숨김을 자동 해제할 수 있다. 이 정책은 온보딩과 SOS 설정에서 명확히 설명한다.

### 정확도 선택

- 정확: 실시간 안전 확인, 장소 알림에 적합.
- 표준: 일반적인 가족/친구 공유에 적합.
- 대략: 친구/커플/여행 후반 또는 사생활 보호에 적합.
- 사람별 정확도 설정을 지원한다.
- 대략 위치는 반경 원으로 표시하고 정확한 주소를 숨긴다.

### 배터리 모드

- 실시간: 위치 업데이트가 빠르며 배터리 사용량 높음.
- 균형: 기본값. 주요 이동과 장소 알림 중심.
- 절전: 업데이트 간격을 늘리고 필요 시 수동 새로고침.
- 배터리 낮음 상태에서는 자동으로 절전 추천 배너를 표시한다.
- 배터리 모드를 바꿔도 SOS와 안전 구역 이탈 같은 긴급 알림은 우선 처리한다.
- 현재 Flutter 안심 화면은 `실시간`, `균형`, `절전` segmented control과 권한 상태 카드를 제공한다.

### 접근성

- 모든 주요 버튼 터치 영역은 최소 44dp 이상.
- 지도 핀은 색상만으로 상태를 구분하지 않는다.
- 고령자 케어 모드는 큰 글자, 높은 대비, 간단한 홈 화면을 제공한다.
- 스크린 리더 라벨:
  - "지우, 학교 근처, 5분 전 업데이트, 배터리 42퍼센트"
  - "내 위치 정확 공유 중, 두 명이 볼 수 있음"
- 모션 민감 사용자를 위해 지도 핀 애니메이션과 카운트다운 진동을 줄일 수 있다.

## 8. MVP 화면별 와이어 설명

### 8.1 시작/온보딩

- 상단: 앱 로고와 짧은 가치 문장.
- 중앙: 세 장의 스와이프 카드.
  - "서로 위치 확인"
  - "도착하면 자동 알림"
  - "위급할 때 SOS"
- 하단: "시작하기" CTA와 "이미 초대받았어요" 보조 버튼.
- 광고 없음.

### 8.2 동의와 권한 안내

- 상단: "위치공유는 동의한 사람끼리만 가능해요."
- 본문: 위치, 알림, 백그라운드 권한이 필요한 이유를 각각 한 줄로 설명.
- 컨트롤: 필수 약관 체크박스, 선택 광고 개인화 체크박스.
- 하단: "동의하고 권한 설정" CTA.
- OS 권한 팝업은 사용자가 CTA를 누른 뒤 순차적으로 요청.
- 광고 없음.

### 8.3 내 프로필/공유 기본값

- 상단: 프로필 사진 또는 이니셜.
- 입력: 이름, 관계 유형.
- 세그먼트: 기본 공유 정확도 정확 / 표준 / 대략.
- 세그먼트: 배터리 모드 실시간 / 균형 / 절전.
- 하단: "다음" CTA.
- 보조 카피: "서클마다 다시 바꿀 수 있어요."

### 8.4 서클 생성/참여

- 카드 2개:
  - 새 서클 만들기
  - 초대 코드로 참여
- 새 서클 만들기 선택 시:
  - 서클 이름 입력.
  - 유형 선택 칩.
  - 공유 기간 선택.
- 참여 선택 시:
  - 초대 코드 입력 또는 링크 자동 인식.
- 하단: 진행 CTA.
- 광고 없음.

### 8.5 초대 공유

- 상단: 생성된 서클 이름.
- 중앙: QR 코드와 초대 코드.
- 액션 버튼: 링크 공유, 연락처 초대, 카카오톡/문자 공유.
- 하단: 초대 문구 미리보기.
- 보조: "초대받은 사람도 위치공유에 직접 동의해야 해요."
- 광고 없음.

### 8.6 지도 홈

- 상단바:
  - 서클 전환 드롭다운.
  - 내 공유 상태 배지.
  - 알림 아이콘.
- 지도:
  - 멤버 핀.
  - 장소 반경.
  - 내 위치 버튼.
- 바텀시트 접힘 상태:
  - 멤버 아바타 행.
  - 각 멤버의 마지막 업데이트 시간과 배터리.
- 바텀시트 중간 상태:
  - 선택 멤버 상세.
  - 전화, 메시지, 길찾기, 장소 알림.
- 우하단: SOS 플로팅 버튼.
- 광고는 바텀시트를 완전히 내린 상태에서만 하단 네이티브 카드로 제한.

### 8.7 멤버 상세

- 상단: 멤버 이름, 관계, 현재 상태.
- 위치 카드: 주소 또는 대략 반경, 마지막 업데이트 시간.
- 상태 카드: 배터리, 네트워크, 이동/정지, 공유 정확도.
- 액션: 전화, 메시지, 길찾기, 알림 설정, 기록 보기.
- 신뢰 문구: "상대가 허용한 범위 안에서 표시됩니다."
- 광고 없음.

### 8.8 장소 알림 설정

- 상단: 지도 미니뷰와 반경 원.
- 입력: 장소 이름.
- 슬라이더: 반경.
- 체크박스: 도착, 출발, 늦음, 장시간 머무름.
- 대상 선택: 멤버 리스트.
- 하단: 조건 요약과 저장 CTA.
- 광고 없음.

### 8.9 SOS 발송

- 기본 상태:
  - 큰 코랄 SOS 버튼.
  - "길게 누르면 바로 보냅니다."
- 카운트다운 상태:
  - 3초 원형 타이머.
  - 취소 버튼.
  - 진동과 음성 안내 옵션.
- 발송 완료:
  - "도움을 요청했어요."
  - 공유된 보호자 목록.

- 광고 없음.

### 8.10 알림 탭

- 상단 필터: 전체 / 장소 / SOS / 배터리 / 조회.
- 알림 리스트:
  - 아이콘, 사람, 이벤트, 시간.
  - SOS는 상단 고정 그룹.
- 일반 알림 5개 이후 네이티브 광고 1개 가능.
- 위험/긴급 알림 주변에는 광고 없음.

### 8.11 기록 탭

- 상단: 날짜 선택.
- 요약 카드: 이동 거리, 주요 장소, 마지막 안전 확인.
- 지도 경로 미리보기.
- 타임라인 리스트.
- 액션: 기록 삭제, 공유, 내보내기.
- 광고: 요약 카드 아래 네이티브 광고 1개 가능. 삭제/내보내기 플로우에는 광고 없음.

### 8.12 프라이버시 설정

- 상단: "현재 내 위치를 볼 수 있는 사람" 요약.
- 사람별 행:
  - 이름, 서클, 공유 정확도, 공유 기간, 마지막 조회.
  - 우측 토글 또는 상세 진입.
- 빠른 액션:
  - 모두 일시 숨김.
  - 대략 위치로 전환.
  - 기록 보관 기간 변경.
- 하단: 데이터 다운로드/삭제.
- 광고 없음.

### 8.13 광고 설정

- 상단: "무료 운영을 위해 광고가 표시됩니다."
- 토글:
  - 개인화 광고.
  - 민감 카테고리 제한.
  - 앱 오픈 광고.
  - 음소거 기본값.
- 보상형 광고 카드:
  - "광고를 보고 24시간 광고 빈도를 줄이기."
  - 기능 해금처럼 보이지 않게 표현한다.
- 광고 미리보기:
  - 네이티브 광고가 어디에 표시되는지 예시.
- 하단: 광고 식별자/파트너 안내 링크.

### 8.14 고령자 케어 홈

- 대상: 고령 가족 계정 또는 보호자 모드에서 선택 가능.
- 화면 구성:
  - 큰 상태 문구: "위치 공유 중"
  - 큰 SOS 버튼.
  - 보호자에게 전화 버튼.
  - 배터리 상태.
  - 마지막 동기화 시간.
- 보호자용 케어 상세:
  - 마지막 위치.
  - 오늘 이동 요약.
  - 장시간 미사용 알림.
  - 안전 구역 이탈 알림.
- 광고 없음.

## 9. MVP 우선순위

### 1차 출시 필수

- 회원가입/로그인.
- 온보딩과 위치/알림 권한.
- 서클 생성/초대/참여.
- 실시간 위치 지도.
- 멤버 상세.
- 장소 도착/출발 알림.
- SOS 발송/수신.
- 위치 기록 30일.
- 프라이버시 설정.
- 광고 설정.
- 네이티브 광고와 보상형 광고.

### 1.5차 개선

- 여행 서클 만료 자동화.
- 고령자 케어 모드 강화.
- 조회 로그 푸시.
- 집결 위치와 중간 지점 추천.
- 운전 리포트.
- 웹 뷰어.

### MVP에서 제외

- 유료 플랜.
- 기능 잠금형 광고.
- 몰래 위치 확인.
- 광고 기반으로 긴급 기능 사용 횟수를 제한하는 구조.

## 10. 디자인 검수 체크리스트

- SOS 플로우 어디에도 광고가 없는가?
- 온보딩에서 위치공유의 상호 동의 원칙이 명확한가?
- 사용자가 내 위치를 볼 수 있는 사람을 2탭 안에 확인할 수 있는가?
- 지도 첫 화면에서 위치 오래됨, 배터리 낮음, 숨김 상태가 오해 없이 보이는가?
- 대략 위치가 정확 주소처럼 보이지 않는가?
- 광고 카드가 실제 컨텐츠와 혼동되지 않도록 라벨링되어 있는가?
- 고령자 케어 화면에서 글자 크기와 터치 영역이 충분한가?
- 장소 알림 저장 전 조건 요약이 자연어로 제공되는가?
- 배터리 모드 변경의 장단점이 한 문장으로 설명되는가?
- 기록 삭제와 데이터 다운로드가 찾기 쉬운가?
