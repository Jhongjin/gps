# 초대, 서클, 동행 세션 플로우

Date: 2026-05-30

## 초대

1. 새 사용자가 서클이 없으면 `create_circle_with_owner`로 첫 서클, owner 멤버십, 기본 공유 정책을 만든다.
2. 기존 서클 멤버가 초대를 만든다.
3. 서버는 원문 토큰을 한 번만 반환하고, DB에는 `invite_token_hash`만 저장한다.
4. 초대 화면은 만료 시간, 1회 사용 여부, 위치 공유 범위, 광고 데이터 분리 안내를 보여준다.
5. 수락자는 앱의 "초대 참여" 카드에 링크 또는 토큰을 입력한다.
6. 수락자는 위치 공유 정책과 광고 동의를 분리해서 선택한다.
7. 수락 RPC가 토큰 해시, 만료, use count, 서클 상태를 확인한 뒤 멤버십과 `consent_events`를 만든다.

## 서클 멤버 상태

- `정확 공유`: 현재 위치와 최근 업데이트 시간이 보인다.
- `균형 공유`: 좌표를 보정해서 보여준다.
- `동네만`: 반경/지역 수준만 보여준다.
- `일시 중지`: 새 위치를 올리지 않고 마지막 상태도 숨긴다.
- `SOS만`: 일반 공유는 꺼지고 SOS fix만 허용한다.

## 동행 세션

1. 시작자가 대상자와 만료 시간을 선택한다.
2. `companion_sessions`를 만들고 각 참여자가 `companion_session_members`에 동의한다.
3. 양쪽 동의 전에는 경로와 위치를 보여주지 않는다.
4. 시작 후 native bridge는 높은 빈도의 위치 수집을 켜고 idempotency key로 업로드한다.
5. 도착 확인, 만료, 직접 종료, 동의 철회 중 하나가 발생하면 native bridge가 즉시 수집을 멈춘다.
6. 세션 경로 샘플은 기본적으로 짧게 보관하고 요약 후 삭제한다.

## 화면 반영

- 지도: 동행 남은 시간, 도착 확인, 경로 꼬리, 배터리/정확도 상태.
- 서클: 초대 코드 힌트, 멤버별 공유 모드, 동행 동의 대기, 장소 알림.
- 프라이버시: 누가 내 위치를 볼 수 있는지, 최근 조회 로그, 모든 공유 일시 중지.
- 기록: 장소 알림, 도착 확인, 동행 종료, 조회 로그 요약.
